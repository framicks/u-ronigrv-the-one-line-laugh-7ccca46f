One funny line, at most 200 characters: a smartwatch, its rings, and a pizza box. Entry for make.fun's "The One-Line Laugh" bounty — a house judge reads the lines two at a time and keeps the bigger laugh.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` when the variable is unset). Running it twice produces byte-identical output, since the line is a fixed string in `main.py` and nothing is read from disk or the network. The script checks the sealed scorer's gate first: the line must be 1 to 200 characters and not only white space.
